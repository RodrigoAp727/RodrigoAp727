## 🏆 PROJETOS EM DESTAQUE

### 🥇 1️⃣ Smart Retail Analytics — Pipeline de Engenharia de Dados 📊

**[Python + PostgreSQL + Docker + GitHub Actions]** | Projeto completo de dados

> Pipeline ETL end-to-end que transforma vendas brutas em métricas prontas para decisão (receita, margem, performance de clientes). Modelagem estrela, SCD Tipo 2, upsert idempotente, testes automatizados e CI rodando.

**Destaques técnicos:**
- 🗄️ Modelo estrela em PostgreSQL com histórico SCD Tipo 2 em `dim_customer`
- 🔁 Upsert idempotente (`ON CONFLICT`) — permite rerun e backfill sem duplicar dados
- ✅ Pipeline testado (pytest) e validado com lint (ruff)
- 🐳 Containerizado com Docker Compose, CI via GitHub Actions
- 📈 Base pronta para consumo em Power BI
